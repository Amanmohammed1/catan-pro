# M5 — The 5–6 player extension

**Goal (PLAN.md):** mostly data plus one phase. Larger board, extra colours,
extra piece stock, a building phase between turns, win threshold stays 10.

Taken before M4 at the user's request, so the interface was designed around six
seats from the start rather than retrofitted.

## What was built

### Rule modules (ADR 0005)

`packages/engine/src/modules/` now exists and golden rule 7 is real: a scenario
names the modules it plays with, `GameConfig.modules` carries that into the
saved state, and `resolveModules()` refuses an unknown id. The base game is a
module too, so the interface is exercised on every game.

Adding the extension touched no base-game rule: `reduce()` gained one call at
end of turn and one phase case, `legalMoves()` one case.

### The board

`classic-5-6.json`, generated by `scripts/generate-classic-scenario.mjs`:

- 30 hexes in rows of 3-4-5-6-5-4-3, two deserts.
- 28 number tokens drawn from a declared bag (ADR 0006 — the lettered order is
  not printed in any rulebook we hold, the composition is).
- 11 harbours: the base nine plus a 2:1 wool and a 3:1 (2022 p.3).
- Supply from the `ext56` module: 24 resource cards of each kind, a 34-card
  development deck.

### The Special Building Phase (ADR 0006)

After a turn ends, every other player in clockwise order gets one window: build
and buy only, no trading of any kind, no development card. `passSpecialBuild`
closes a window; the last one starts the next player's turn. Reaching ten points
in a window does not win until your own turn.

### Everywhere else

The lobby offers 3–6 seats, the server picks the board from the seat count, and
hot-seat does the same. Player cards tighten up for five and six.

## Acceptance

| Check                                  | Result                            |
| -------------------------------------- | --------------------------------- |
| `pnpm verify`                          | green — 500 fast tests, 9 slow    |
| `pnpm fuzz` (classic, 4 players)        | 10,000 games, 0 stalled           |
| `pnpm fuzz --players 5 --scenario classic-5-6` | 10,000 games, 19.5M actions, 0 stalled |
| `pnpm fuzz --players 6 --scenario classic-5-6` | 10,000 games, 22.4M actions, 0 stalled |

Wins are spread evenly across all six seats, which is the signal that the
building window is not handing an advantage to a particular position.

## Notes for later

- Paired players (the rule that officially replaced this phase in 2022) is not
  implemented. It would be a second module; ADR 0006 says what that would take.
- If the official disc order ever turns up, switching is a data change only.
