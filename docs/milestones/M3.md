# M3 — The 3D client

**Goal (PLAN.md):** it looks good. Done when a stranger can look at it and not
ask "is this finished?"

## What was built

The first pass (commits `2da01ce`…`8970cca`) put a real 3D board on the screen:
instanced tiles and pieces, invisible click proxies, clamped orbit controls, a
DOM overlay for every piece of text, and the accessible placement list that the
UI tests drive the game through.

The second pass (`982a7b8`, `59fb596`) is the one that met the goal.

### Two defects that made it look broken

Both passed every test, because nothing checked the picture:

1. `debug.css` styled `body` directly and was imported on every screen. As
   unlayered CSS it beat the design system's layered base: near-black text on
   dark panels, a pale lobby, monospace everywhere.
2. The tile slab's top face sat at y = 0.35 while every piece was placed at
   `BOARD_TOP` = 0.11, so number tokens and roads rendered *inside* the tiles
   and settlements showed only their roof tips.

`geometries.test.ts` now measures the real meshes against the constant, and
`pnpm shots` renders the app in a headless browser so a human looks at the
result before the work is called done.

### The warm-tabletop redesign

- Terrain painted to canvas per type, with instanced props (trees, peaks,
  sheep, sheaves, clay pits, stones) seeded by tile id.
- Number tokens as a rim plus a printed face, upright and legible, red 6 and 8,
  6 and 9 barred.
- Reshaped pieces with a dark inverted-hull outline, a wooden sea frame, water,
  harbour piers with painted rate signs, warm key light, bloom and vignette.
- A camera fit that binary-searches the real projection, so the board fills its
  panel at any window shape.
- Design tokens, Fraunces and Inter (OFL, self-hosted), original card art, a
  layout that stacks below 900px, and keyboard shortcuts.

## Acceptance

- `pnpm verify` green.
- `pnpm shots` at 1600×1000, 1280×800 and 390×844: tokens legible, pieces
  clearly visible, all text above WCAG AA (enforced by `theme.test.ts`), whole
  board in frame, no console errors.

## Not done, carried to M4

- No sound. Howler is not installed.
- No glTF models — deliberately, see ADR 0004; everything is generated.
- Frame rate still not measured on a low-powered machine. The meter is there
  (Stats in the top bar) and `PerformanceMonitor` drops effects automatically,
  but nobody has run it on integrated graphics.
- Animations are still CSS and `useFrame`, not driven by the event stream.
